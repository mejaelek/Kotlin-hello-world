 # Overview

As a software developer, I'm using this project to get my development environment, Git workflow, and submission process set up for the semester before diving into the graded CSE 310 modules — starting with Kotlin, the language I chose for Module #1.

This software is a simple "Hello World" console program written in Kotlin. It prints a greeting to the screen to confirm that Kotlin is installed and configured correctly on my machine.

My purpose in creating this software was to verify my toolchain (Kotlin, Git, VS Code) works end-to-end and to practice the full workflow I'll repeat for every module this semester: write code, document it, record a walkthrough, and publish it to a public GitHub repository.

Software Demo:https://youtu.be/CfU83IdOICI 

# Development Environment

I used Visual Studio Code as my editor, along with the Kotlin command-line compiler to build and run the program. Version control was handled with Git, and the finished code is published on GitHub.
